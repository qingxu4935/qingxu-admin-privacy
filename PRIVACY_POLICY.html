隐私政策（青序后台 / Qingxu Admin）

生效日期：2026-10-06 · 开发者：Qingxu4935

一句话

青序后台把数据留在你自己的设备上：不收集、不上传、不共享任何个人信息，没有遥测、没有广告、没有第三方分析 SDK。

我们收集什么

什么都不收集。应用不发送崩溃报告、不统计使用行为、不含任何第三方分析 SDK，也没有账号体系外的服务器——所有持久化内容都只写在你自己这台机器上。应用只在你自己的设备上保存“你正在用的这份演示/自建数据”，包括：

  • 账号与凭据：用户名、昵称、角色、部门、锁定状态，以及口令的 PBKDF2-SHA256 哈希（10 万次迭代 + 每账号随机盐）。口令明文不落盘、不传输。
  • 你录入的业务数据：订单 / 订单行 / 客户 / 商品等记录、数据字典、系统参数、公告与已读状态、附件元数据与附件字节。
  • 界面状态：主题与布局设置、菜单树改动、表格列宽与筛选状态、审计日志、权限策略快照、当前登录会话、离线写队列。
  • 个人化内容：你为自己账号选的头像图片。

你的数据存在哪里

桌面版（全部在本机，不经过任何服务器）：

  • 主要数据走 Akavache，落在 machine store（不是 %LOCALAPPDATA%）：
    C:\ProgramData\IsolatedStorage\...\AssemFiles\Qingxu4935.Admin\LocalMachine\LocalMachine.db
    这是一个 SQLite 文件，存账号与口令哈希、设置、菜单树、审计日志、权限策略、部门树、会话、业务记录、字典、参数、公告、附件元数据与离线写队列。从 Microsoft Store 安装时，其中落在 %LOCALAPPDATA% 的部分位于应用的包容器目录下。
  • 附件字节：%LOCALAPPDATA%\Qingxu4935.Admin\files\<32 位十六进制>.bin（一附件一文件）。
  • 若在设置里把数据源切成 SQLite 文件：%LOCALAPPDATA%\Qingxu4935\QingxuAdmin\admin-users.db（只放用户表；首次启动自建并播种演示用户）。

Web 版（只在这台机器的浏览器里）：持久化落在 IndexedDB 数据库 qingxu-admin，登录会话另存一条记录。

导入 / 导出的文件：落点由你在系统文件对话框里选（导出 Excel、打印 PNG 等），应用不复制、不留副本；Web 版导出走浏览器下载，落点由浏览器决定。

什么时候会联网

默认状态下应用自己不发起任何网络请求：不上传数据、不检查更新、不回调服务端。只有下面三种显式动作会联网，且都由你触发或由你配置：

  1. 你配置了外部身份提供方时（OAuth2 / OpenID Connect）：点登录按钮后，应用请求你配置的 issuer 发现文档，并在本机临时起 http://127.0.0.1:<port>/callback 接收回调，然后把授权码换成令牌。未配置（issuer / clientId 为空）时该提供方判为未就绪，不联网。
  2. 演示页的「打开 PDF / 打开视频」按钮：会把公开示例地址交给系统默认浏览器。应用本身不内嵌浏览器、不预取；点之前不联网，之后的访问由那个网站自己负责。
  3. 数据源选 REST 时：当前版本尚未实现该网关，选中后只记一条警告并继续用演示数据，不发起请求。将来接入后端时，本政策会先更新并写明发送什么、发到哪里。

应用不声明 internetClient 能力。

怎么删

桌面版：先退出应用（运行中的应用会锁库文件），然后

  • 清全部数据：删掉 C:\ProgramData\IsolatedStorage\...\AssemFiles\Qingxu4935.Admin\LocalMachine\ 下的 LocalMachine.db，以及 %LOCALAPPDATA%\Qingxu4935.Admin\files\ 整个目录；下次启动会重新播种演示数据。
  • 只重置凭据（保留其它数据）：删除存储键 admin_accounts_v1 后重启。
  • 清 SQLite 用户库：删掉 %LOCALAPPDATA%\Qingxu4935\QingxuAdmin\admin-users.db。
  • 装成 MSIX（Microsoft Store）时：%LOCALAPPDATA% 里的写入落在包的私有存储，卸载即随包删除；C:\ProgramData 下的 machine store 不在包内，卸载不会替你清，要按上面手动删。

Web 版：在浏览器站点数据里删掉 IndexedDB 数据库 qingxu-admin（或直接清站点数据）即抹掉全部持久化内容。

儿童与年龄分级

应用不面向儿童、不含广告、不收集任何数据；Microsoft Store 年龄分级为 4+。应用内的演示数据（订单、客户、商品、账号）全部是本机播种的样例，与真实个人无关。

权限说明（MSIX 清单）

能力用途
runFullTrust 桌面（Win32）应用打包为 MSIX 所必需；提供对文件系统的正常访问，用于上面那些本机数据与你主动导入 / 导出的文件

变更

若未来版本新增联网功能（例如云同步或 REST 后端），本政策会先更新并写明发送什么、发到哪里，再发布该版本。
